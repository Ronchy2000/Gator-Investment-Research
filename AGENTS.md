# AI Agent Instructions

## Testing Policy

- AI agents must not run tests in this repository.
- Do not run automated test suites, unit tests, integration tests, smoke tests, browser or UI validation, crawler trial runs, or other test-related commands.
- Do not install dependencies for the purpose of running tests.
- Do not create or modify test files unless the user explicitly requests it in the current task.
- After making changes, state that tests were not run according to this repository policy.
